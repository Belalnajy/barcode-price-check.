# استعلام الأسعار — Barcode Price Check

تطبيق استعلام أسعار بالباركود (عربي/إنجليزي) مبني بـ **React** (فرونتإند) + **Node.js/Express** كـ Serverless Functions (باكإند) + قاعدة بيانات **Postgres** — جاهز للنشر مباشرة على **Vercel**.

## المميزات

- 🔍 مسح الباركود بالسكانر أو الكيبورد أو **كاميرا الموبايل**
- 📷 **مسح متواصل بالكاميرا**: الكاميرا بتفضل مفتوحة وبتأكدلك كل صنف مكانه (اسمه وسعره) وانت ماسك السلة — من غير ما تقفل وتفتح كل مرة. والصنف اللي سايبه قدام العدسة مش بيتضاف مرتين
- ⚡ الكاميرا بتستخدم `BarcodeDetector` المدمج في المتصفح لما يكون متاح (أسرع، ومن غير أي تحميل إضافي)، وبترجع لمكتبة `html5-qrcode` بس على المتصفحات اللي مش بتدعمه
- 🔤 بحث بالاسم: المطابقة الحرفية الأول، وبعدين تصحيح إملائي (Fuse.js)، مع تطبيع الحروف العربية والأرقام الهندية
- ⌨️ تنقّل بالكيبورد في نتائج البحث (`↑` `↓` `Enter`)
- 🛒 قائمة مشتريات بكميات وإجمالي شامل ضريبة القيمة المضافة 15%
- 📦 كتالوج 1399 صنف محفوظ في قاعدة بيانات مشتركة بين كل الأجهزة
- 🗂️ **إدارة كاملة للقائمة**: تصفّح كل الأصناف وتدوّر فيها بالاسم أو الباركود، وتعدّل أو تحذف أي صنف، وتضيف أصناف يدوي من غير ما تحتاج شيت أصلًا
- 📴 نسخة محفوظة على الجهاز: التطبيق بيفتح فورًا من غير انتظار، وبيفضل شغال لو السيرفر وقع (مع تنبيه واضح)
- 📥 **رفع أكتر من ملف Excel مرة واحدة** (ضم أو استبدال) مع معاينة الفروقات قبل التطبيق، وتقدر تشيل ملف من المجموعة والحسبة تتظبط لوحدها، وتنزيل CSV، ورجوع للأصل
- 🖨️ طباعة القائمة في جدول مرتّب على A4
- 🌗 وضع نهاري/ليلي بيتبع إعداد النظام لحد ما تختار بنفسك
- 🔔 نغمة مختلفة لكل حالة (موجود / من غير سعر / مش موجود) مع إمكانية الكتم
- 🌐 واجهة ثنائية اللغة: عربي (خط **Cairo**) / إنجليزي (خط **Inter**)
- 📄 صفحة باركودات للتجربة: `/test-barcodes.html`

## واجهة الـ API

| Method | Path | الوظيفة |
|---|---|---|
| GET | `/api/health` | حالة السيرفر ونوع قاعدة البيانات |
| GET | `/api/products` | كل الأصناف + معلومات القائمة (مع ETag → 304 لو مفيش تغيير) |
| GET | `/api/products/:barcode` | صنف واحد بالباركود |
| POST | `/api/products` | إضافة/تعديل صنف واحد |
| DELETE | `/api/products/:barcode` | حذف صنف من القائمة |
| POST | `/api/products/bulk` | استيراد جماعي `{ mode: "merge"\|"replace", items: [...] }` |
| POST | `/api/products/reset` | الرجوع للقائمة الأصلية |

قائمة المشتريات (السلة) تظل على الجهاز نفسه (localStorage) — زي التطبيق الأصلي بالظبط — بينما الكتالوج والأسعار مشتركة من قاعدة البيانات. لو سعر اتغيّر في الكتالوج، سطور السلة بتتحدّث تلقائيًا عشان ما تفضلش شايلة سعر قديم.

## التشغيل محليًا

```bash
npm run install:all      # أو: npm install && npm --prefix frontend install
npm run dev              # API على :3001 + Vite على :5173
npm test                 # 89 اختبار (vitest)
npm run build
```

بدون `DATABASE_URL` يشتغل الـ API بقائمة في الذاكرة (غير دائمة) — كافية للتجربة المحلية.

## النشر على Vercel

1. **أنشئ قاعدة البيانات**: من لوحة Vercel → **Storage** → **Create Database** → اختر **Postgres (Neon)**. أو أنشئ قاعدة مجانية من [neon.tech](https://neon.tech) وانسخ الـ connection string.
2. **اربط المشروع**: من [vercel.com/new](https://vercel.com/new) استورد هذا الريبو من GitHub. إعدادات البناء تُقرأ تلقائيًا من `vercel.json` — لا تغيّر شيئًا.
   > ⚠️ لو ظهر **Framework Preset: Express** في شاشة الاستيراد، غيّره إلى **Other**. وجود `express` في dependencies يخدع الاكتشاف التلقائي فيحاول Vercel نشر المشروع كسيرفر واحد بدل (فرونت ثابت + API functions). ملف `vercel.json` يفرض `"framework": null` لمنع ذلك، لكن تأكيدها في الواجهة أيضًا لا يضر.
3. **أضف متغير البيئة**: في إعدادات المشروع → **Environment Variables** أضف:
   - `DATABASE_URL` = connection string بتاع Postgres (لو أنشأتها من لوحة Vercel بيتضاف لوحده باسم قد يكون `POSTGRES_URL` — انسخ قيمته إلى `DATABASE_URL`).
4. **Deploy**. أول طلب للـ API بينشئ الجداول ويزرع الكتالوج الأصلي (1399 صنف) تلقائيًا.

> ملاحظة: كاميرا الموبايل تتطلب HTTPS — وهذا متوفر تلقائيًا على Vercel.

## حسابات الضريبة

الضريبة بتتحسب على إجمالي الطلب مش على كل سطر لوحده، وكل رقم بيتقرّب مرة واحدة:

```
سعر الحبة شامل الضريبة = round2(price × 1.15)
إجمالي السطر            = round2(سعر الحبة شامل الضريبة × qty)
المجموع قبل الضريبة      = round2(Σ round2(price × qty))
الضريبة                 = round2(المجموع × 0.15)
الإجمالي                = round2(المجموع + الضريبة)
```

كده الأرقام المعروضة على الشاشة والمطبوعة بتجمع بالظبط من غير فروق كسور. الاختبارات في `frontend/tests/cart.test.js` بتغطي الحالة دي.

## الأداء

- **تقسيم الحزم**: كود التطبيق (~19 KB gz) منفصل عن React (~45 KB gz) وعن مكتبات المسح (~23 KB gz)، فأي تحديث للتطبيق ما بيبطّلش كاش المكتبات.
- **تحميل كسول**: `xlsx` (143 KB gz) بينزل بس لما ترفع ملف، و`html5-qrcode` (100 KB gz) بينزل بس على المتصفحات اللي مالهاش `BarcodeDetector`.
- **بداية فورية**: الكتالوج بيتقري من نسخة الجهاز أول ما الصفحة تفتح، والتحديث من السيرفر بيحصل في الخلفية.
- **ETag**: لو الكتالوج ما اتغيّرش، السيرفر بيرد 304 بدل ~140 KB.

## التجربة بدون سكانر

افتح `/test-barcodes.html` — فيها باركودات EAN-13 سليمة تقدر:
- تكتب أرقامها بالكيبورد وتدوس Enter،
- أو تفتحها على اللابتوب وتمسحها بكاميرا الموبايل من التطبيق،
- أو تطبعها وتجرب عليها بالسكانر الحقيقي.
